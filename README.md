## Stack
Pure HTML · CSS · Vanilla JS — no framework, no build step needed.

## Deploy to GitHub Pages (2 minutes)

1. Push this repo to GitHub as `suyash07.github.io` (exact username)
2. Go to repo Settings → Pages → Source: main branch / root
3. Your site goes live at `https://suyash07.github.io`

**OR** name it anything (e.g. `portfolio`) and it deploys to `suyash07.github.io/portfolio`

## Deploy to Vercel
1. Import repo to vercel.com
2. Framework: Other
3. Deploy — done

## Customization
All content is in `index.html`. Key sections to update:
- Hero stats (update numbers as your career grows)
- Projects section (add Uber project link once deployed)
- Resume download link (replace `#` with your resume PDF URL)
